# Property due-diligence API workflow

A due-diligence application needs reproducible facts, provenance, and explicit review states.

The [due-diligence recipe](../../recipes/15-due-diligence/) combines property resolution and optional zoning, keeps unknowns intact, and leaves customer-defined screening logic outside the API response.

Use it as a foundation for acquisition review, brokerage research, lender or investor workflows, and internal property triage. It is not a legal zoning opinion, appraisal, title opinion, or permit assurance.
