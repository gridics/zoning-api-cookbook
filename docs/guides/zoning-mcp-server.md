# Zoning MCP server and property-data tools

Gridics exposes Model Context Protocol connections through the Public API and Developer Portal so AI clients can use structured property and zoning tools instead of receiving raw credentials or copied zoning documents.

The canonical Public API MCP path is /mcp. The Developer Portal supplies the correct deployment connection and authorization flow for the current environment.

Use the [MCP integration guide](../../integrations/mcp/) and [recipe 16](../../recipes/16-mcp-tools/) to understand bounded tool design, then use the hosted Developer Portal connection for supported production clients.
