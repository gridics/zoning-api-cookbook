# Support

- Account, plan, geography, and API-key access: use the Gridics Developer Portal or contact `sales@gridics.com`.
- Cookbook bug or unclear example: open a GitHub issue with the recipe, language, runtime version, redacted request ID, and error. Never attach an API key or customer property dataset.
- Security or exposed credential: follow [SECURITY.md](SECURITY.md).

The examples demonstrate the public API contract. Current plan terms, coverage, field availability, quotas, and billing shown in the Developer Portal take precedence over checked-in sample text.
