# Maintenance and distribution

Repository maintainer: **Gridics Engineering Team**.

Gridics owns the examples and distributes the code under the checked-in Apache-2.0 license and NOTICE. Credentials, customer data, confidential implementation details, and internal operational information are not example content and must never be committed.

The Gridics Engineering Team reviews public API contract changes, runtime support, dependencies, fixtures, security reports, and release evidence. Preserve the declared runtime compatibility until the documented support matrix changes. Review dependency majors against the complete seven-language fixture and MCP matrix.

Normal CI is credential-free and fixture based. Bounded production Public API verification is separate and must retain only public-safe metadata. An unavailable capability remains explicit; fixture success must never be represented as live verification.

Changes to repository visibility or public release status require explicit authorization and completion of the public-release checklist.
